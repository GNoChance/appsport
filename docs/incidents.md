# Registre des incidents

Registre des incidents de sécurité d'appsport (03 §14). Conduite à tenir, détaillée en P8 « Vol, cambriolage ou fuite » :

1. couper l'accès : révoquer les partages Tailscale ou arrêter le service ;
2. évaluer ce qui a été exposé ;
3. prévenir les proches concernés sous 72 h : ce qui s'est passé, ce qu'ils doivent faire ;
4. consigner l'incident ici, par une PR : une ligne par incident.

Chaque ligne donne la date, les faits, les données exposées, les mesures prises et les personnes prévenues (par pseudo). Elle ne contient jamais de donnée de santé, de mot de passe, de code, de jeton ni d'autre secret.
